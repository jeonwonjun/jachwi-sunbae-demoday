# 자취선배 서비스 소개

- 넘기기: → · 스페이스 · 클릭 / 뒤로: ←
- N: 발표 대본 · M: 시연 화면 전환(웹→앱 / 전부 웹 / 전부 앱) · F: 전체 화면 · Home: 처음으로

## 화면 이미지 넣는 곳

같은 이름의 파일을 넣으면 바로 바뀝니다. 파일이 없으면 화면에 "화면 넣기" 자리 표시가 보입니다.
웹은 `img/web/` (1440×900 권장), 앱은 `img/app/` (780×1688 권장), 모두 `.jpg`입니다.

| 파일 이름 | 쓰이는 곳 |
|---|---|
| home | 표지, 엔딩 (서비스 첫 화면) |
| explore-search | 시연 1 동네 찾기: 목적지 검색 |
| explore-map | 시연 2 동네 찾기: 통근 지도 |
| interest | 시연 3 관심 지역 저장 |
| room-add | 시연 4 지도에 방 등록 |
| room-nearby | 시연 5 등록한 방 주변 교통·편의시설 |
| memo | 시연 6 지도 위 개인 메모 |
| checklist | 시연 7 체크리스트 |
| list | 시연 8 기록한 방 목록 |
| compare | 시연 9 방 비교 |

기본 모드(웹→앱)에서는 시연 1~3이 웹, 4~9가 앱 화면을 씁니다. `index.html`의 `let MODE = 'mix';`를 `'web'` 또는 `'app'`으로 바꾸면 한 가지로 통일됩니다.

## 두 가지 버전
- `index.html` 발표용: 키보드로 넘기는 방식입니다. N은 대본, F는 전체 화면입니다. 시연은 웹(동네 찾기·관심 지역) → 앱(방 기록부터) 순서로 보여 줍니다.
- `video.html` 영상용: 약 84초 동안 자동으로 재생되고 처음으로 돌아갑니다. 스페이스나 클릭으로 일시정지, R로 처음부터 재생합니다. 진행 표시, 대본, 커서는 숨겨집니다.
- 영상 녹화 전에 `img/web/`과 `img/app/`의 빈 화면 슬롯을 먼저 채워 주세요. 빈 슬롯은 안내 문구로 표시됩니다.
